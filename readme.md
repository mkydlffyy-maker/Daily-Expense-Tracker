# Daily Expense Tracker

Aplikasi web sederhana untuk mencatat pengeluaran dan mengatur anggaran harian.

Proyek ini dibuat sebagai latihan HTML, CSS, dan JavaScript sekaligus mencoba membuat aplikasi yang berguna untuk kehidupan sehari-hari.

## Fitur

- Mengatur anggaran harian
- Menambahkan pengeluaran berdasarkan kategori
- Menghitung total pengeluaran secara otomatis
- Melihat sisa anggaran
- Menghapus pengeluaran

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript

## Cara Menjalankan

1. Clone atau download repository ini.
2. Buka folder proyek.
3. Jalankan file `index.html` melalui browser.

Tidak perlu instalasi tambahan.

## Catatan

Proyek ini masih dalam tahap pengembangan. Saat ini, data pengeluaran dan anggaran hanya tersimpan sementara dan akan hilang ketika halaman dimuat ulang.
